# Angle Lab – قياس الزوايا (PWA)

## النشر على GitHub Pages
1. أنشئ Repository جديد (مثلًا `angle-lab`) وارفع كل الملفات: `index.html` و`manifest.json` و`sw.js` و`icon-192.png` و`icon-512.png`.
2. من Settings ← Pages: Source = Deploy from a branch، الفرع `main`، المجلد `/ (root)`، ثم Save.
3. بعد دقيقة افتح `https://USERNAME.github.io/angle-lab/`.
4. على الموبايل: Chrome ← ⋮ ← Install app، أو Safari ← مشاركة ← Add to Home Screen.

## عند تعديل الملفات
غيّر رقم `anglelab-v1` داخل `sw.js` (مثلًا `v2`) ليصل التحديث للهاتف.
